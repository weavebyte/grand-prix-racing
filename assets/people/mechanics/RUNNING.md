# 사진풍 달리기 메카닉 — v0.9.6

도구: built-in image_gen, identity-preserve. transparent_background=true. CLI 미사용. 각 팀별 기존 PNG를 참조한 개별 편집 호출.
각 파일은 2×2 달리기 프레임 아틀라스. 기존 정비 이미지와 함께 사용.
